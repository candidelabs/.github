## 👋 Welcome

Welcome to Candide Labs! We're building open-source infrastructure for **Ethereum Account Abstraction (EIP-4337)**. Whether you're looking to integrate smart wallets, run a bundler, or explore cutting-edge wallet technology, you're in the right place.

**New here?** Start with our [📚 Documentation](https://docs.candide.dev/)

## 🚀 Core Repositories

### For Developers

<table>
  <tr>
    <td width="140px" align="center"><img src="https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/typescript.svg" width="48" height="48" alt="TypeScript" /></td>
    <td>
      <b><a href="https://github.com/candidelabs/abstractionkit">AbstractionKit</a></b><br/>
      A TypeScript library to easily build and deploy ERC-4337 Smart Wallets with first-class support for Safe accounts. Perfect for integrating account abstraction into your dApp.
      <br/><br/>
      <code>npm install abstractionkit</code>
    </td>
  </tr>
  <tr>
    <td width="140px" align="center"><img src="https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/python.svg" width="48" height="48" alt="Python" /></td>
    <td>
      <b><a href="https://github.com/candidelabs/voltaire">Voltaire</a></b><br/>
      A modular and lightning-fast Python bundler for Ethereum EIP-4337 Account Abstraction. Built for performance and scalability.
      <br/><br/>
      <code>pip install voltaire-bundler</code>
    </td>
  </tr>
  <tr>
    <td width="140px" align="center">⚙️</td>
    <td>
      <b><a href="https://github.com/candidelabs/candide-contracts">Candide Contracts</a></b><br/>
      Production-ready smart contracts including social recovery modules, paymasters, BLS signature support, and more. All contracts are audited and battle-tested.
    </td>
  </tr>
  <tr>
    <td width="140px" align="center">💳</td>
    <td>

      JSON-RPC API reference for Candide's paymaster service. Enable gasless transactions and ERC-20 gas payments for your users.

  </tr>
