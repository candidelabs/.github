Welcome to the Candide GitHub! We build open source tooling for Ethereum smart account infrastructure. From SDKs and plugins to Bundler and Paymaster services. If you don't know where to start, head to the [docs](https://docs.candide.dev/).

---

| See working code examples | [abstractionkit-examples](https://github.com/candidelabs/abstractionkit-examples) |

## SDKs and Examples

- [**abstractionkit-examples**](https://github.com/candidelabs/abstractionkit-examples) — Step-by-step examples: creating accounts, sending gasless transactions, passkey auth, and more
- [**AbstractionKit SDK**](https://github.com/candidelabs/abstractionkit) — TypeScript library for building with Safe accounts and EIP-7702, with first-class support for passkeys, gas sponsorship, and social recovery
- [**Tether WDK x Candide**](https://github.com/candidelabs/tether-wdk-candide) — Examples for using Tether's Wallet Development Kit with Candide

## Demos
- [**Safe Passkeys Demo**](https://github.com/candidelabs/safe-passkeys-react-example) — React app showcasing passkey authentication with Safe accounts
- [**Safe Unified Account Demo**](https://github.com/candidelabs/safe-unified-account-react-demo) — React demo for multichain Safe accounts with unified signatures
- [**Safe React Native Passkeys Demo**](https://github.com/candidelabs/passkeys-react-native-demo) — React Native demo for passkey-based Safe accounts on mobile

## Smart Contracts

- [**candide-contracts**](https://github.com/candidelabs/candide-contracts) — Social recovery module, paymaster contracts, BLS helpers, and audit reports

## Infrastructure

- [**Voltaire**](https://github.com/candidelabs/voltaire) — Modular and lightning-fast Python Bundler for ERC-4337 Account Abstraction
- [**Paymaster API**](https://docs.candide.dev/wallet/paymaster/rpc-methods/) — JSON-RPC API reference for Candide's gas sponsorship service

## Apps

- [**Safe Cover**](https://github.com/candidelabs/safecover) — Frontend for Safe account recovery: manage guardians and complete recovery flows
